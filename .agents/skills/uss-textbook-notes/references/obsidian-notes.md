# Obsidian 教材笔记结构

教材子目录使用 `原始资料/`、`笔记/`、`附件/`、`_extracted/`、`.course_index/`、`_working/`。原件默认一份；已有原件在别处时记真实路径，不为每个章节复制 PDF。实际建立的入口为 `00_教材入口.md`，列出教材书目、学习单元、章节导航、完成范围和 syllabus 映射。按内容需要建立附件，不生成空目录或空章节。

章节命名用稳定 `第01章-主题.md`，分节可用 `01-02-主题.md`，保留原书章号，不随重新排序重命名已有笔记。正文用 `$...$` 和 `$$...$$`，代码块注明语言，图片用同课程附件相对路径；图题、表题和定理编号保留。内部导航可用 `[[第01章-主题]]`，出现同名章时加路径消歧；精确来源用标准 Markdown `[原书物理第12页](../原始资料/book.pdf#page=12)`，页码片段不伪造印刷页号。引用路径须按实际目录计算。

YAML 属性示例（使用实际信息；未知字段省略或明确写 unknown）：

```yaml
---
type: textbook-chapter
course: MAxxx
book: "实际书名"
edition: "实际版次"
chapter: "1"
source_sha256: "实际哈希"
physical_pages: [12, 30]
status: drafted
tags: [教材笔记, 线性代数]
---
```

每章按内容设置：学习目标与先修、概念和符号、定理与条件、推导或算法、例子、图表说明、易错点、原书练习定位、来源与待核对项、上一章/下一章导航。不要求每章套满这些标题；有学习内容才写。callout 可用 `[!definition]`、`[!theorem]`、`[!warning]`、`[!example]`，纯 Markdown 仍须可读。

完成状态只表示实际阶段，不能用 `reviewed` 标记未查看的原页。课堂遗漏章标为选读，主教材未覆盖的教学目标列为缺口，其他书的补充应链接其独立目录。
