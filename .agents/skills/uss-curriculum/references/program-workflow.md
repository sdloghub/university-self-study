# 专业 workflow

先读取 `专业/SUSTech/培养方案/2026/整理结果/` 与现有 MIT 专业材料，确认已提取范围与缺口。文件哈希/版本未变时复用，不重做扫描。新文件按配置专业提取目标、毕业要求、课程组、最低学分、互斥/替代、先修、通识与适用年级；跨专业共用课程去重但保留角色。

目录以 `专业/SUSTech/`、`专业/MIT/`、`专业/Stanford/` 分学校，各专业用稳定名称/代码目录。SUSTech 既有跨专业表保留在培养方案索引中，各专业入口链接对应提取结果；MIT 已有 catalogs/programs 分区可保留，避免重新复制。Stanford 无材料时只记录待整理状态。跨校对照在 `专业/专业比对/`，不混入某本教材目录。

按用户范围查询学校官方培养方案/degree requirements 与院系目录，确认本科/研究生、学位、修订年份、学分制度。比较专业核心、方向选择、先修路径、数学/算法/数据/经济学/社会学能力与不足，标注共同主题及不能直接比较之处。使用 MIT 官方目录/院系与 Stanford 官方 Bulletin/院系；OCW 是课程教学材料，不当作现行专业要求。

产出带证据的培养地图、专业差异、建议路径和待核对清单，南科大毕业基线与外校补充、个人目标分开。不认证学分等价/毕业资格，不从专业比对自动下载所有课程 syllabus 和教材。具体课程交课程 workflow。
