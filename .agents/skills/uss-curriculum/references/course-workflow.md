# 课程 workflow

## 1. 确定课程

用户未指学校默认 SUSTech；通过现有培养方案代码入口核对名称与代码，再查 https://mirrors.sustech.edu.cn/courses/syllabus/ 实际列表中的 PDF/HTML。后缀不猜成学年，镜像无匹配时找 SUSTech 院系官方来源，仍缺失则记录。用户指定其他学校或已有 syllabus 时遵从，版本歧义实质影响选择才澄清。

## 2. syllabus 原件与索引

下载实际 PDF 到 `课程/<学校>/<代码-名称>/syllabus/`，核对能打开且确为 syllabus，保存 URL、哈希、版次/学期、页数。原站只给 HTML 就保留网页快照，可导出并明确标为网页导出 PDF，不能冒充官方 PDF。课程入口引用本地 PDF，汇总课程目标、先修、教学日历、考核、required/reference 教材及精确来源页。获取失败记录缺口，不能用一份自编摘要替代声称已下载的原件。

## 3. required 主教材

提取 required/必读与 recommended/reference，保留原始分类。对 required 候选建立“教学周/主题—教材章/节—先修/深度—缺口”适配表，以实际目录/全文核对教学日历，不凭书名选择。先比较教学日历适配度，再比较指定版次、内容覆盖、可获取性；无需虚构数值精度。保存主本及选择理由、替代本和未覆盖部分。无教学日历时以 syllabus 主题作暂定映射，无 required 时从实际推荐书中选暂定主本，说明依据。

记录书名、作者、版次、语言、ISBN 和 syllabus 来源页。优先开放/授权资源；获取不到主本时继续 syllabus/已可用内容，临时替代明确标注，不能因获取容易把不适配书改为主本。原件按书名/版次/页数/哈希核对，登录 HTML 不当 PDF。

每一本书放课程下 `教材/<作者-书名-版次>/`，无文字层交自动 OCR，再调用 uss-textbook-notes 整理单元/章节 Obsidian Markdown。按页与教学日历保持来源关系；同本同版复用原件和已有笔记。默认执行主教材全范围的章节整理，明确 syllabus 必需和教材扩展。

## 4–6. 可选模式

- 多教材：用户启用时匹配 MIT、Stanford 或指定学校的相似课程，按主题、先修、深度、成果和考核比较，保存课程年份与官方来源。按同样 1–3 步处理其 syllabus 和 required 主本；多个教材子目录均在当前课程，保留学校/课程来源标记，建立跨书主题映射。不是默认拼接 PDF 或混写正文。
- 生成：基于实际已核对的章节与要求，用 uss-notes/uss-assessment 生成用户指定教材、笔记合集、PS、试卷，注明外校补充所需知识。题卷、答案、评分和能力矩阵可追溯；参考材料未到时说明自主蓝图。
- 翻译：用户指定某本英文 PDF 后使用 uss-textbook-translate，翻译目录与笔记分离，默认中文 Markdown 与排版 PDF，不用摘要替代完整翻译。

三个模式可组合，缺页和 OCR 待办不影响独立检索，但依赖缺失原文的生成/翻译必须等待证据。保存完成状态与版本，续做保护人工编辑。
