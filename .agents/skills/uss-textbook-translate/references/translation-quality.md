# 翻译的术语、版式与核验

术语表至少含英文、中文、学科语境、首次来源页、采用依据和歧义备注。优先原教材定义与学科通行术语；查词典/标准/学校材料时保存实际依据。一个英文词不同语境可不同译法，但必须解释差异。不要机械把 field、ring、normal、significant 等按日常词义翻译。

保持原书定义/定理/引理/推论/例题/图表/公式编号，章节节号不因译文分页改变。命题中的“当且仅当”“存在”“任意”“至少”“至多”以及假设不能省略。证明翻译保留步骤和因果关系，不把译者推导混入。原书错误可加译注，原文和修正依据分别记录。

源页对照建议用 JSONL：`chapter`、`section`、`block_id`、`physical_page`、`printed_page`、`kind`、`output_file`、`output_anchor`、`status`、`uncertainty`。不要求每段附长引用扰乱阅读，页映射单独保存；章节开头标原书页范围，必要的精确定位可链接原件。

中文 PDF 使用可嵌入的中文正文字体与兼容数学字体、清楚的标题层级、舒适的行距和页边距。图题表题随图表，代码保持等宽，长公式适当分行且等式关系不变，跨页长表重复表头；页面美观不能以删除内容为代价。PDF 至少检查文字可提取、字体缺字、目录与书签、章节完整性、公式与图表编号连续性。

先样排：含公式/证明的一页、含图的一页、含长表或代码的一页；根据书的实际内容选择，不制造不需要的测试。全文逐块覆盖核对、关键数学和术语核对、渲染抽样是三种不同检查。保存真实检查范围；未渲染页不能标为已视觉核对。
