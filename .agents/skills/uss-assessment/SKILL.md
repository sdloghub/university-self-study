# PS 与能力试卷

先读 uss AGENTS.md、培养方向配置、目标课程复合大纲与已核对材料；按 [原题流程](references/questions.md) 与 [共享证据规范](../uss-source-index/references/evidence_quality.md) 记录原题。只在用户要求时生成。

## 参考材料与蓝图

收到 PS/考卷时保留原件，提取完整题干、代码、选项、图、条件、年份、来源物理页码及答案依据。图片题用模型识图补充，缺图或未识别条件的题暂不作为可靠样本。区分学校官方试卷、用户笔记及未知来源；不要从少量参考卷推断历年频率或命题概率。

先建立蓝图：主题 × 能力类型 × 难度 × 分值/预计时间 × 大纲来源。能力按学科选用概念辨析、证明/反例、计算推导、算法设计与复杂度、编程/调试、建模、数据分析、结果解释与跨学科迁移。无需每张试卷包含所有类型。南科大要求和补充内容分开列示；复合卷中说明补充题需哪些额外知识。

用户已给范围、时长、难度、题量和格式就直接执行；缺失时根据大纲及参考材料写出可修改的默认值。实质性课程范围不明确时先澄清，同时核对参考材料。明确 PS 训练目标与考卷测评目标，避免把相同难题堆砌成两种产物。

## 生成与核验

题目标为原题、改编或新编；原题/改编链接来源，保留原题记录。答案无来源时标 agent 推导。自编题使用新措辞和适量背景，不大段复刻受版权保护的题库。先求解再发布题卷，确保条件充分、答案可判定，开放题给评分标准和可接受路径。

交付学生题卷（不含答案）、教师答案与评分标准、能力覆盖矩阵；PS 可按用户偏好把提示与答案另列。每题给主题、能力、分值、预计时间、难度依据和来源类别。核对总分、时长估计、知识先修、各能力覆盖及答案；代码题在环境可用且已审查时运行，数学题核对边界情形与推导。运行验证、推理核对和未验证分开记录；主观难度/预计时间不是实测成绩。

后续参考卷到来时，比较蓝图、题型、难度和评分方式，增量调整并记录版本，不覆盖用户已改的试卷。未给参考卷时说明“按复合大纲自主设计”，不冒充南科大或 MIT 真题/预测卷。
